# Junk Drawer 1.7.1 — Everyday tasks first

- A more compact utility layout replaces the oversized drop zone and promotional copy.
- Home and the compact tray panel now lead with smaller files, image-to-JPG, PDF merge, MP4, MP3, and image resizing.
- JPG, MP4, and MP3 are the default outputs. Other everyday formats remain visible; specialist outputs are behind an All formats toggle. Older camera footage remains supported as input.
- Removed 11 catalog entries: frame capture, podcast loudness, volume leveling, silence cutting, editor-specific phone-video repair, icon generation, picture tracing, background-color filling, JSON formatting, JSON/YAML conversion, and duplicate batch-media conversion. Batch processing remains in the normal converter.
- Start with Windows is optional and disabled for first use. The app remains visible in Windows Settings → Apps → Startup even when disabled. Junk Drawer's switch honors Windows changes. Settings includes a direct Windows startup-apps button.
- Tooltips wait one second and cancel when you leave the tool.
- Vector tracing's native route and packaged binary were removed.

Install this release from the update banner or the Windows installer below. Restart/install remains an explicit user action.
